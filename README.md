# Массивы

Решения домашних заданий по теме «Массивы»:

- `task1/main.cpp` — вывод массива на экран;
- `task2/main.cpp` — поиск минимального и максимального элементов;
- `task3/main.cpp` — двумерный массив и индексы минимального и максимального элементов;
- `task4/main.cpp` — сортировка массива обратным пузырьком.

## Компиляция и запуск

Пример для задания 1 из корня проекта:

```powershell
g++ task1/main.cpp -std=c++17 -Wall -Wextra -pedantic -o task1/main.exe
.\task1\main.exe
```

Для остальных заданий замените `task1` на `task2`, `task3` или `task4`.
